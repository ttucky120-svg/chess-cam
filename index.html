♞ หมากรุกกล้องสด

กำลังโหลด engine…
กด เปิดกล้อง แล้วตั้งมือถือให้มองเห็นกระดานทั้งหมดจากด้านบน
(ถ้าเปิดกล้องสดไม่ได้ ใช้ ถ่ายรูป แทน)
เริ่มจากตำแหน่งตั้งต้นของเกม แล้วเปิดกล้อง
ไม่แน่ใจว่าเดินตาไหน — เลือกให้หน่อย:
วิธีใช้ให้แม่น
  1. วางมือถือนิ่งๆ เหนือกระดาน (ขาตั้ง/พิงของ) ให้เห็นครบ 64 ช่อง แสงสม่ำเสมอ
  2. กด ตั้งมุมกระดาน แล้วแตะมุมนอกของกระดานตามลำดับ a1 → h1 → h8 → a8 (a1 = มุมซ้ายล่างเมื่อมองจากฝั่งขาว ที่เรือขาวยืน) ลากจุดมุมปรับทีหลังได้
  3. จัดหมากเป็นตำแหน่งเริ่มต้น (หรือตรงกับกระดานด้านขวา) แล้วรอขึ้นว่า “พร้อม”
  4. เดินหมากตามปกติ เอามือออกจากกระดาน ระบบจะรอภาพนิ่ง ~1 วิ แล้วตรวจว่าเดินตาไหน (เทียบกับตาเดินที่ถูกกติกาทั้งหมด)
  5. ถ้าจับผิด กด ↩️ ย้อน แล้วแตะเดินบนกระดานด้านขวาเอง จากนั้นกด จับภาพอ้างอิงใหม่
ระบบไม่ได้ “อ่าน” ชนิดหมากจากภาพ แต่ดูว่าช่องไหนเปลี่ยน แล้วจับคู่กับตาเดินที่ถูกกติกา จึงต้องเริ่มจากตำแหน่งที่ถูกต้องเสมอ
